PROJECT 03 / 자연어 처리

응급 상황 기록·분류 지원

응급 상황의 음성과 텍스트 단서를 처리하고 핵심 정보를 정리하는 교육용 AI 서비스 프로젝트입니다. Whisper 음성 인식, OpenAI API를 통한 GPT 계열 모델의 요약·키워드 추출, BERT 텍스트 분류를 하나의 흐름으로 연결했습니다.

  • Python
  • OpenAI API
  • GPT 계열 모델
  • Whisper
  • BERT
  • Transformers
데모 체험 구현 내용 보기소스 코드 실제 서비스
구현 내용처리 흐름체험형 데모평가 관점

주요 구현 내용

수행 내용

  • Whisper를 활용한 음성 인식(STT)으로 응급 상황의 음성 입력을 텍스트로 변환했습니다.
  • OpenAI API로 GPT 계열 모델을 연계하여 변환된 텍스트를 요약하고 핵심 키워드를 추출하는 흐름을 구현했습니다.
  • BERT 모델 파인튜닝을 통해 응급 상황을 등급별로 분류하는 기능을 구현했습니다. 교육용 프로젝트이며 실제 의료 판단을 대신하지 않습니다.

기술 구성
