PROJECT 04 / 시계열 분석

상품 판매량 예측

과거 시계열 데이터로 상품 판매량을 예측하는 프로젝트입니다. 데이터 탐색과 전처리, 시계열 특성 생성, 기준선 비교를 통해 예측 오차를 분석했습니다.

  • Python
  • 1D CNN
  • LSTM
  • pandas
  • scikit-learn
데모 체험 구현 내용 보기소스 코드 실제 서비스
구현 내용처리 흐름체험형 데모평가 관점

주요 구현 내용

수행 내용

  • 유가, 방문자 수 등 외부 요인의 영향을 EDA로 분석하고 결측치 처리, 이상치 제거, 시계열 특성 생성을 수행했습니다.
  • 판매량 예측에 1D CNN과 LSTM을 적용하고 베이스라인 회귀모델과 비교했습니다.
  • RMSE·MAE 지표로 성능을 평가하고 재고 최적화 관점에서 예측 결과를 분석했습니다.

기술 구성

과거 판매량과 외부 요인을 분석하고 1D CNN·LSTM 및 회귀 기준선을 비교한 수요 예측 프로젝트.
