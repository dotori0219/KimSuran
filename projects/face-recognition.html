실시간 얼굴 인식 시스템

영상 속 얼굴을 탐지하고 특징 벡터를 활용해 등록된 대상과 비교하는 실시간 얼굴 인식 프로젝트입니다. 데이터 품질과 환경 변화가 인식에 미치는 영향을 함께 살펴보았습니다.

  • Python
  • YOLO
  • FaceNet
  • OpenCV
  • Roboflow
데모 체험 구현 내용 보기소스 코드 실제 서비스
구현 내용처리 흐름체험형 데모평가 관점

주요 구현 내용

수행 내용

  • 팀원별 얼굴 이미지 2,000장을 수집하고 이미지 증강을 적용했으며, Roboflow로 라벨링과 전처리를 수행했습니다.
  • FaceNet으로 128차원 특징 벡터를 추출하고 YOLO를 활용한 실시간 얼굴 인식 파이프라인을 구현했습니다.
  • 하이퍼파라미터를 조정하고 로컬 실시간 테스트 및 다양한 환경에서의 성능 평가를 진행했습니다.

기술 구성

  • Python
  • YOLO
  • FaceNet

  • Roboflow

얼굴 이미지 수집과 라벨링부터 YOLO·FaceNet 기반 인식, 로컬 실시간 테스트까지 연결한 비전 파이프라인.
